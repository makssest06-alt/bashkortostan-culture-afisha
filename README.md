# Афиша культуры Башкортостана

Приватный репозиторий команды для подготовки к хакатону «Кибер 102» и разработки единой достоверной афиши культурных событий республики.

## Продукт

Планируемые интерфейсы:

- веб-сервис с поиском и фильтрами;
- Telegram-бот;
- открытый REST API и встраиваемый виджет;
- ИИ-агент для разбора свободных запросов, уточняющих вопросов и объяснения подборки.

Ключевое ограничение: мероприятия должны быть проверяемыми. ИИ не является источником событий и работает только с данными из единого каталога.

## Текущий этап

Подготовка к хакатону. Сначала исследование, границы MVP и архитектурные решения, затем каркас разработки и сквозное демо. Кодовая архитектура и технологический стек пока не зафиксированы.

## Базовые принципы

1. Один источник данных для сайта, бота, API и виджета.
2. У каждого события есть источник, время последней проверки и статус.
3. Сначала сквозной MVP, затем дополнительные функции.
4. Изменения попадают в `main` через короткие ветки и pull request.
5. Секреты, токены и персональные данные не хранятся в репозитории.
6. Каждое демонстрируемое событие можно проверить по первоисточнику.

## До начала разработки

- Добавить всех участников команды в collaborators с минимально необходимыми правами.
- Включить защиту `main`: запрет прямых push и force-push, обязательный PR и минимум одно ревью.
- Назначить владельцев направлений и заполнить таблицу в `docs/DECISIONS.md`.
- Согласовать состав MVP и критерии готовности демо.

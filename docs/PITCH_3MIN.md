# Афиша культуры Башкортостана — финальная демонстрация

На показ решения три минуты, затем четыре минуты на вопросы. Откройте заранее Telegram, каталог, виджет и вкладку «Трассы ИИ» в админке. Войти в админку стоит до начала записи, чтобы токен не попал в кадр.

| Время | Что показать | Что сказать |
|---|---|---|
| 0:00–0:15 | `/start` в Telegram | «Покажу, как житель подбирает событие и подписывается на афишу. Бот, сайт и виджет работают с одним каталогом». |
| 0:15–1:20 | «Куда пойти завтра?» → «В Уфе» → карточка → подтверждение подписки | «Бот уточняет город, сохраняет дату и подбирает события из каталога. В карточке есть дата, площадка, возраст и цена, если она указана. Подписка сохраняется после подтверждения». |
| 1:20–2:05 | Каталог на сайте → фильтры в адресной строке → карточка с источником → предпросмотр виджета | «Подборкой можно поделиться ссылкой. Для площадки или портала есть встраиваемый виджет и REST API с контрактом OpenAPI». |
| 2:05–2:40 | «Трассы ИИ» в админке → свежий запрос из Telegram | «По трассе видны условия, вызов поиска, ID карточек и время ответа. На стенде работают правила, поэтому запросы не расходуют токены модели». |
| 2:40–3:00 | Последний слайд со ссылками и результатами | «На нашем наборе верны 120 из 120 действий, 13 из 13 уточнений по нужному полю и 25 из 25 сквозных сценариев. На стенде синтетический каталог. Официальный набор заказчик не предоставил». |

Если подписка уже есть у демонстрационного аккаунта, заранее удалите её через меню «Подписки». Резервная запись может повторять этот же маршрут.

## Короткие ответы на вопросы

- **Откуда данные?** Организаторы подтвердили, что подготовленного набора нет, и предложили открытые источники. На стенде синтетические события с меткой `synthetic: true`. CSV и JSON загружаются через админку. Повторный тестовый импорт 100 строк прошёл без создания дублей.
- **Нужна ли внешняя модель?** На стенде `rules-v2` обрабатывает свободный текст, задаёт уточнения и ведёт диалог. Бэкенд также поддерживает LLM и гибридный режим. Обработка возвращается к правилам при ошибке провайдера или исчерпании бюджета.
- **Что означают цифры?** Это результаты открытого набора команды. На дополнительных 10 запросах из аудита PR #23 правильны 10 действий и все 6 ожидаемых уточнений. Эти запросы использовались для исправлений. Для приёмочного замера нужны независимые запросы.
- **Что обеспечивает трасса?** Можно сверить карточки по их идентификаторам. Для замера точности свободного текста нужно отдельно проверить утверждения ответа по источникам.
- **Отправляются ли уведомления?** Подписку можно создать и удалить. Автоматическая рассылка пока отсутствует.

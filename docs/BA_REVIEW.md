# Башкирская версия сайта: вычитка и строки для носителя языка

Вычитка 13.11.2026, ветка `feat/web-site`. Переводчик не носитель языка: всё ниже нужно показать носителю до защиты.

## Что проверено

- Все строки с пометкой «проверить» (общий словарь, главная).
- Общий словарь целиком: `web/src/lib/i18n/dict.ba.ts` (347 строк).
- Подписи страниц `/ask` (`web/src/components/ask/copy.ts`), `/events/[id]` (`web/src/components/event/copy.ts`), `/about` (`web/src/components/about/copy.ts`) и формы заявки, которая стоит на `/about` и в карточке (`web/src/components/feedback/OrganizerForm.tsx`).
- Названия городов и категорий (`web/src/data/dictionaries.ts`).

Всего 602 строки.

## Как проверено

1. **Буквы.** Инвентарь всех небазовых букв по кодам Unicode: ә ө ү ғ ҡ ң ҙ ҫ һ и заглавные — только башкирские коды. Казахских двойников (қ ұ і), латинских (ə h ç), татарской җ и латиницы внутри кириллических слов нет.
2. **Татарские и калькированные формы.** Поиск ч в исконных словах, г/к в словах с задними гласными (в башкирском ғ/ҡ), татарских слов (белән, өчен, кирәк, бу, эзләү, күрсәтү, сайлау).
3. **Смысл и согласованность.** Чтение каждой пары «русский → башкирский»: одинаковые понятия одними словами, кнопки в одной грамматической форме, короткие нейтральные формы для интерфейса.

## Оставлено на русском намеренно

- Примеры запросов к ИИ-подбору (`ask.placeholder`, `ask.example1…4`) и пример на главной: ассистент пока понимает только русский, нажатие на пример отправляет его как запрос. На странице об этом сказано (`ask.langNote`).
- Ответы ассистента, подписи его чипов и причины подбора приходят из API на русском.

# Дополнительный прогон ТЗ 9.2-4 на 10 запросах

[Набор из 10 запросов](../evals/search/clarification-challenge.jsonl) подготовлен при аудите PR #23 и зафиксирован коммитом `4735b35` до правок этого раунда. Он включает 6 неоднозначных запросов и 4 запроса, по которым можно сразу искать. Два примера с названиями в кавычках взяты из уже обнаруженных регрессий. Для официальной приёмки требуется независимый набор проверяющих.

| Проверка | `main` `c1365d3` | PR до правок `23e95bc` | PR после правок |
|---|---:|---:|---:|
| Вопрос вместо поиска, полный набор команды | 9/13 (69,2%) | 13/13 (100%) | **13/13 (100%)** |
| Вопрос вместо поиска, 10 дополнительных запросов | 2/6 (33,3%) | 6/6 (100%) | **6/6 (100%)** |
| Меньший результат из двух замеров по формуле 9.2 | 33,3% | 100% | **100%** |
| Нужное поле первого вопроса, дополнительные запросы | 1/6 | 6/6 | **6/6** |
| Правильное действие на всех 10 запросах | 6/10 | 8/10 | **10/10** |
| Лишние вопросы на 4 запросах с ожидаемым поиском | 0/4 | 2/4 | **0/4** |

Метрика 9.2-4 учитывает долю неоднозначных запросов, на которые задан вопрос без выдачи. Поэтому её знаменатель для этого набора равен 6. Коды вопросов и лишние уточнения проверялись отдельно. Извлечение всех фильтров и релевантность результатов по этим 10 запросам не оценивались. Для исходного `main` использован проверочный скрипт с тем же критерием ответа, поскольку у штатного раннера на том коммите отсутствует `--external`.

| ID | Ожидание | `main` | PR до правок | PR после правок |
|---|---|---|---|---|
| EXT-01 | `audience` | поиск | `audience` | `audience` |
| EXT-02 | `city` | поиск | `city` | `city` |
| EXT-03 | `date` | поиск | `date` | `date` |
| EXT-04 | `child_age` | поиск | `child_age` | `child_age` |
| EXT-05 | `budget` | `contradiction` | `budget` | `budget` |
| EXT-06 | `location` | `location` | `location` | `location` |
| EXT-07 | поиск | поиск | `date` | поиск |
| EXT-08 | поиск | поиск | поиск | поиск |
| EXT-09 | поиск | поиск | поиск | поиск |
| EXT-10 | поиск | поиск | `audience` | поиск |

В `EXT-07` и `EXT-10` текст в кавычках теперь сохраняется как название. Отдельный тест API проверяет, что после ответа «Можно платные» поиск продолжается с прежними городом, датой и категорией. Перед правкой эти проверки падали. После неё прошли 67 тестов бэкенда и 25 сквозных сценариев.

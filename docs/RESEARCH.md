# План исследования аналогов и технических подходов

Статус: запланировано как следующий самостоятельный этап. Этот файл содержит методику, а не готовые выводы.

## Вопросы исследования

1. Какие региональные и федеральные сервисы уже решают похожую задачу?
2. Как они представляют фильтры, статусы, источники, цены и возрастные ограничения?
3. Какие открытые данные и официальные источники доступны для Башкортостана?
4. Как агрегаторы организуют импорт, нормализацию, обновление и дедупликацию?
5. Как совместить естественный диалог с строгим структурированным поиском?
6. Какой минимальный API и виджет удобно подключить внешнему сайту?
7. Какие решения реально повторить командой за время хакатона?

## Направления поиска

- Официальные культурные порталы и афиши регионов.
- Федеральные афиши, билетные агрегаторы и событийные платформы.
- Telegram-боты и диалоговые интерфейсы поиска событий.
- Открытые API и форматы данных событий.
- Документация и исследования по entity resolution, record linkage и fuzzy matching.
- Практики structured output, function calling и ограничения галлюцинаций.
- Подходы к встраиваемым виджетам и публичной API-документации.

## Критерии сравнения аналогов

| Критерий | Что оцениваем |
|---|---|
| Достоверность | Источник, дата проверки, статусы, обработка отмены |
| Поиск | Дата, город, цена, возраст, категория, свободный запрос |
| Качество данных | Дубли, полнота полей, обновление, нормализация |
| UX | Число шагов, мобильный сценарий, пустые состояния |
| Интеграция | REST API, документация, виджет, ограничения |
| ИИ | Уточнения, объяснимость, работа только с реальными данными |
| Реализуемость | Трудоёмкость, риски, польза для демо и оценки |

## Требования к качеству

- Каждый факт подкрепляется ссылкой на первоисточник или проверяемый пример.
- Отделяем наблюдения от собственных предложений.
- Не копируем интерфейс или архитектуру только потому, что они есть у крупного сервиса.
- Оцениваем пригодность именно для задачи и сроков хакатона.
- Итогом должны быть решения и компромиссы, а не просто список ссылок.

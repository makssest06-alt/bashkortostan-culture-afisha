# Соответствие ТЗ

Источник: официальное ТЗ, задача 1 «Афиша культуры Башкортостана», файл [`docs/TZ.pdf`](TZ.pdf).
Дата сверки: 2026-11-13. Таблица честно показывает, что есть в репозитории сейчас, а не что планируется.

## Как читать

**Статус:**

- **есть** — сделано и влито в `main`;
- **PR #17** — сделано на сайте в открытом [PR #17](https://github.com/makssest06-alt/bashkortostan-culture-afisha/pull/17) (ветка `feat/web-site`), в `main` ещё нет;
- **в работе (PR #17)** — делается в PR #17 прямо сейчас;
- **контракт** — описано в `contracts/` или `docs/`, кода нет;
- **нет** — нет ни кода, ни контракта.

**Владелец:**

- **фронт** — сайт, виджет и интерфейс админки (`web/`);
- **бэк** — REST API, база, импорт, дедупликация, модерация, логи и метрики, `docker compose`;
- **бот** — Telegram-бот и ИИ-агент. Ядро агента общее для бота и сайта, сайт рисует интерфейс `/ask`.

Распределение агента между «бот» и «фронт» — предложение, его надо подтвердить на созвоне.

**Чего нет в репозитории совсем:** бэкенда, бота, агента с моделью, базы данных и миграций, `docker-compose.yml`, корневого `.env.example`. Сайт в PR #17 работает на API-заглушках внутри Next.js (`web/src/app/api/v1/`) и 39 синтетических событиях (`web/src/data/mock/`).

**Уровень:** в README предложен уровень 3 «Агент» (85 баллов), его ещё надо согласовать с командой. Уровень 4 в таблице заполнен полностью, но помечен как вне предложенного уровня.

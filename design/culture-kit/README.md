# Bashkir Culture Kit

Визуально-культурная база Башкортостана для дизайна афиши: орнамент кускар, тамбурная вышивка, символы (курай, герб, знамя Салавата), костюм и серебро, юрта, петроглифы Шульган-Таш (ЮНЕСКО-2025), природа и ландмарки, современное использование мотивов и письменность.

## С чего начать
1. **CATALOG.md** — сводный каталог: топ-находки, палитра из 8 HEX с происхождением, 10 приёмов внедрения в дизайн афиши, предостережения по лицензиям.
2. **research/culture-brief.md** — культурный бриф (~2100 слов, с источниками): значения мотивов, история, символы.
3. **gallery-site/index.html** — офлайн-галерея всех 113 референсов (открыть в браузере; картинки подтягиваются из `thumbs/`, которые появятся после загрузки изображений).
4. В каждой папке `0X-*/manifest.md` — таблица «файл → что изображено → ценность для дизайна».

## Структура
- `01-ornament-kuskar/` — орнамент кускар, мотивы, бордюры-раппорты (10 файлов)
- `02-vyshivka/` — тамбурная вышивка, золотое шитьё, полотенца (16 файлов)
- `03-symbols/` — курай, герб РБ, знамя Салавата Юлаева 1773 г. (9 файлов)
- `04-kostyum-ukrasheniya/` — костюм, елән, кашмау, серебро (яга, селтәр) (12 файлов)
- `05-yurta-byt/` — юрта, кереге, интерьеры, быт (11 файлов)
- `06-shulgan-tash/` — петроглифы Каповой пещеры, знаки-глифы (14 файлов)
- `07-nature-landmarks/` — Салават Юлаев, Иремель, мёд, кони, Агидель (26 файлов)
- `08-modern-branding/` — векторные эмблемы курая, полосы узора, «Урал-батыр», арабица (15 файлов)

## Изображения
Сами изображения (~137 MB) не лежат в этом коммите: их загружает `scripts/push-culture-kit.sh` из распакованного архива кита. Текстовый слой (манифесты) уже на месте и описывает каждый файл.

## Лицензии
Изображения собраны из открытых источников как референсы для вдохновения. В продукт узоры идут перерисованными вектором; файлы с вотермарками — только для просмотра (помечены в манифестах).
